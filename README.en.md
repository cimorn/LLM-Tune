# LLM-Tune

[中文](README.md) · English

LLM-Tune is a project for fine-tuning small language models. It lets you compare methods such as supervised fine-tuning and reinforcement learning across models and datasets.

## Running the project

Run these commands from the project root with Python 3.11 and a PyTorch environment that supports CUDA BF16.

```bash
python -m pip install -r requirements.txt
python main.py --dry-run
python main.py
```

Set `MODEL`, `DATASET`, `ALGORITHM`, and `STEP` in [main.py](main.py). The default runs base model evaluation, SFT, GRPO, and PPO with Qwen3-0.6B on the calculator task. You can also set options on the command line. For example, `python main.py --model DeepSeek-R1-1.5B --dataset calculator --step compare` rebuilds the charts and results pages after you have run the experiment locally.

`STEP` accepts `1`, `2`, `3`, `all`, or `compare`. When you run a training stage on its own, the program checks and reuses completed prerequisites. `ALGORITHM` accepts `GRPO`, `PPO`, or `both`.

## Configuration and results

- `step1_LLM/Models/<model>/model.json` stores the model source, revision, and loading settings.
- `step2_SFT/Configs/<model>/<dataset>.json` stores the SFT parameters.
- `step3_Tune/RL/<algorithm>/Configs/<model>/<dataset>.json` stores the parameters for each RL method.
- `Outputs/<dataset>/<model>/` stores each stage's evaluations, logs, weights, and charts. `Outputs/<dataset>/README.en.md` summarizes the dataset's experiment results in English.
