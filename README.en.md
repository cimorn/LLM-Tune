## Run

Use Python 3.11 with CUDA BF16 PyTorch.

```bash
python -m pip install -r requirements.txt
python main.py --dataset calculator --algorithm DPO
python main.py --dataset calculator --step test --algorithm DPO
```

Use `--step 3 --algorithm DPO` to continue a completed SFT run. `--algorithm both` remains the default GRPO/PPO sequence. Use `--algorithm all` for GRPO, PPO, and DPO.

For Kaggle, place `train.csv` and `test.csv` under `Datasets/human_preference/raw/` or pass `--input-dir`.

```bash
python main.py --dataset human_preference --algorithm DPO --train-limit 1536 --val-limit 256
python main.py --dataset ToolACE --model Qwen3-0.6B --algorithm all
python main.py --dataset ToolACE --model Qwen3-0.6B --step test --algorithm all
```

ToolACE uses the archived 694/100/250 split. Set `--model` for each model. New runs go to `Outputs/ToolACE/`.

## Configuration and results

- `step1_LLM/Models/<model>/model.json` stores the model source, revision, and loading settings.
- `step2_SFT/Configs/<model>/<dataset>.json` stores the SFT parameters.
- `step3_Tune/RL/<algorithm>/Configs/<model>/<dataset>.json` stores parameters for each method.
- `Outputs/<dataset>/<model>/` stores each stage's evaluations, logs, weights, and charts. `Outputs/<dataset>/README.en.md` summarizes the dataset's experiment results in English.
